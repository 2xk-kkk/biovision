🚪 跨膜运输方式对比

运输方式方向载体/通道能量举例
自由扩散高→低不需要不耗能O₂、CO₂、甘油、乙醇
协助扩散高→低需要（载体/通道蛋白）不耗能葡萄糖进红细胞、水(水通道蛋白)
主动运输低→高需要（载体蛋白）消耗ATPNa⁺/K⁺、葡萄糖进小肠上皮细胞
质壁分离实验要点：
✓ 材料：紫色洋葱鳞片叶外表皮（有紫色大液泡，易观察）
✓ 外界溶液 > 细胞液浓度 → 细胞失水 → 质壁分离
✓ 外界溶液 < 细胞液浓度 → 细胞吸水 → 质壁分离复原
✗ 死细胞、动物细胞不能发生质壁分离
  • 被动运输 = 自由扩散 + 协助扩散（顺浓度梯度，不耗能）重点
  • 自由扩散：不需要转运蛋白，顺浓度梯度重点
  • 协助扩散：需要转运蛋白（载体/通道），顺浓度梯度重点
  • 水分子主要通过水通道蛋白以协助扩散方式进出细胞理解
  • 原生质层 = 细胞膜 + 液泡膜 + 两层膜之间的细胞质（相当于半透膜）重点
  • 质壁分离的条件和复原原理重点
  • 载体蛋白与通道蛋白的区别（构象改变 vs 不结合）理解

第2节 主动运输与胞吞、胞吐

▼

主动运输

物质逆浓度梯度（低→高）
需要载体蛋白协助
需要消耗能量（ATP）
体现了细胞膜的选择透过性

胞吞

大分子/颗粒物进入细胞
细胞膜向内凹陷包围 → 囊泡
消耗能量
例：白细胞吞噬细菌、变形虫摄取食物

胞吐

大分子排出细胞
囊泡与细胞膜融合 → 释放内容物
消耗能量
例：分泌蛋白（消化酶、抗体、激素）

胞吞与胞吐的结构基础：细胞膜的流动性（不是选择透过性！）
此过程需要消耗能量，但不需载体蛋白，不属于跨膜运输。
  • 主动运输：逆浓度梯度，需载体蛋白，消耗ATP重点
  • 主动运输体现了细胞膜的选择透过性理解
  • 胞吞和胞吐利用细胞膜的流动性重点
  • 胞吞胞吐消耗能量但不需载体，不属于跨膜运输理解
  • 三种跨膜运输方式的判断方法理解
