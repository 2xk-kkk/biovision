第1节 降低化学反应活化能的酶

▼

⚡ 酶的作用机理 - 降低活化能

酶的本质和作用：
✓ 本质：蛋白质或RNA（绝大多数是蛋白质）
✓ 作用：降低化学反应的活化能（不改变平衡点，不改变化学反应的ΔG）
✓ 特性：高效性、专一性、作用条件温和

高效性

酶的催化效率比无机催化剂高10⁷ ~ 10¹³倍
实验验证：比较H₂O₂在不同条件下的分解

专一性

一种酶只能催化一种或一类化学反应
实验验证：淀粉酶对淀粉和蔗糖的水解

条件温和

需要适宜的温度和pH
高温、强酸、强碱会使酶变性失活（不可逆）
低温只是抑制酶活性（可恢复）

  • 酶的本质：蛋白质或RNA（绝大多数是蛋白质）重点
  • 酶的作用机理：降低活化能（不改变平衡！）重点
  • 酶的三大特性：高效性、专一性、条件温和重点
  • 高温/强酸/强碱→ 酶变性失活（不可逆）理解
  • 低温→ 酶活性降低但可恢复（不破坏结构）理解
  • 最适温度和最适pH的概念理解

第2节 细胞的能量"货币"ATP

▼

🔋 ATP结构 - 交互演示

ATP全称：腺苷三磷酸（Adenosine Triphosphate）
结构简式：A — P ~ P ~ P（"~"代表高能磷酸键）
功能：细胞生命活动的直接能源物质（不是主要能源！葡萄糖是主要能源）

ATP ↔ ADP 的相互转化

ATP ⇌ ADP + Pi + 能量
（水解酶/合成酶催化）
时刻进行，不可逆（酶不同）

ATP的来源

动物：细胞呼吸
植物：细胞呼吸 + 光合作用
ATP含量在细胞内很少，但转化极快

  • ATP是细胞生命活动的直接能源物质重点
  • ATP结构简式：A—P~P~P（2个高能磷酸键）重点
  • ATP与ADP的相互转化（酶不同，不可逆）理解
  • 能源物质排序：糖类（主要）> 脂肪（储能多）> ATP（直接）重点

第3节 细胞呼吸的原理和应用

▼

🏭 有氧呼吸三阶段 - 交互导图

有氧呼吸总方程式：
C₆H₁₂O₆ + 6H₂O + 6O₂ → 6CO₂ + 12H₂O + 能量
阶段场所反应物产物产能
第一阶段（糖酵解）细胞质基质葡萄糖2丙酮酸 + 4[H]少量（2ATP）
第二阶段（柠檬酸循环）线粒体基质丙酮酸 + H₂OCO₂ + [H]少量（2ATP）
第三阶段（氧化磷酸化）线粒体内膜[H] + O₂H₂O大量（34ATP）
无氧呼吸：
① 产生酒精和CO₂：C₆H₁₂O₆ → 2C₂H₅OH + 2CO₂ + 少量能量（酵母菌、大多数植物）
② 产生乳酸：C₆H₁₂O₆ → 2C₃H₆O₃ + 少量能量（动物、乳酸菌、马铃薯块茎）
第一阶段与有氧呼吸完全相同，都在细胞质基质中进行
  • 有氧呼吸三阶段的场所（基质→线粒体基质→线粒体内膜）重点
  • 有氧呼吸总方程式（重点：H₂O在反应物和产物中都出现）重点
  • O₂在第三阶段参与反应，与[H]结合生成H₂O重点
  • CO₂产生于第二阶段（第一阶段不产生CO₂！）重点
  • 无氧呼吸的两种类型（酒精发酵 vs 乳酸发酵）及代表生物重点
  • 无氧呼吸只在第一阶段释放少量能量（其余存留在酒精/乳酸中）理解
  • 细胞呼吸的意义：为生命活动提供能量理解

第4节 光合作用与能量转化

▼

🌿 光合作用全过程 - 交互导图

光合作用总方程式：
6CO₂ + 12H₂O →(光能,叶绿体) C₆H₁₂O₆ + 6O₂ + 6H₂O
比较项目光反应暗反应（碳反应）
场所类囊体薄膜叶绿体基质
条件需要光、色素、酶不需光，需要酶、ATP、NADPH
过程水的光解 + ATP和NADPH的合成CO₂的固定 + C₃的还原
产物O₂、ATP、NADPH（CH₂O）、ADP、NADP⁺
能量转化光能→活跃的化学能活跃的化学能→稳定的化学能
色素提取与分离：
提取：用无水乙醇（研磨法）→ 溶解色素
分离：用层析液（纸层析法）→ 不同色素在滤纸上扩散速度不同
结果（自上而下）：胡萝卜素（橙黄）→ 叶黄素（黄）→ 叶绿素a（蓝绿）→ 叶绿素b（黄绿）
  • 光合作用的场所：叶绿体（类囊体薄膜+基质）重点
  • 四种光合色素及在层析纸上的顺序记忆
  • 光反应：类囊体薄膜上，水光解产生O₂，生成ATP和NADPH重点
  • 暗反应：叶绿体基质中，CO₂固定（C₅+CO₂→2C₃），C₃被还原重点
  • 光反应为暗反应提供ATP和NADPH重点
  • 光合作用总方程式（O₂全部来自H₂O的光解！）重点
  • 影响光合作用的因素：光照强度、CO₂浓度、温度、水等理解
